# 工具链、格式矩阵与安全边界

## 三层依赖

| 层 | 依赖 | 覆盖范围 | 缺失时 |
|---|---|---|---|
| 核心（内置） | Python 3.8+ 标准库：`zipfile` `tarfile` `gzip` `bz2` `lzma` `zlib` | 全部 13 项动作 + zip / tar / gz / bz2 / xz 读写 | 不需要安装任何东西 |
| 可选增强 | `pyzipper` | 加密 zip 升级为 AES-256 | 自动降级为传统 ZipCrypto（弱加密，明确告知） |
| 可选增强 | `py7zr` | 7z 读写 | 报一条安装提示，不静默失败 |
| 可选增强 | `rarfile` + `unrar` / `bsdtar` 二进制 | rar **只读** | 报一条安装提示 |

```bash
pip install pyzipper      # AES-256 加密 zip
pip install py7zr         # 7z
pip install rarfile       # rar 读取（还需系统 unrar）
python scripts/actions.py check
```

本技能**不联网、不自动安装依赖、不上传压缩包**；`online` 注册表全为 null。

## 格式矩阵

| 格式 id | 扩展名 | 读 | 写 | 多文件 | 注释 | 密码 |
|---|---|---|---|---|---|---|
| `zip` | .zip / .jar | ✅ | ✅ | ✅ | ✅ | ✅ AES-256（pyzipper）/ ZipCrypto（内置） |
| `tar` | .tar | ✅ | ✅ | ✅ | — | — |
| `tgz` | .tar.gz / .tgz | ✅ | ✅ | ✅ | — | — |
| `tbz2` | .tar.bz2 / .tbz2 | ✅ | ✅ | ✅ | — | — |
| `txz` | .tar.xz / .txz | ✅ | ✅ | ✅ | — | — |
| `gz` | .gz | ✅ | ✅ | ❌ 单文件 | — | — |
| `bz2` | .bz2 | ✅ | ✅ | ❌ 单文件 | — | — |
| `xz` | .xz | ✅ | ✅ | ❌ 单文件 | — | — |
| `7z` | .7z | 需 py7zr | 需 py7zr | ✅ | — | ✅ |
| `rar` | .rar | 需 rarfile | ❌ | ✅ | — | 部分 |

`gz` / `bz2` / `xz` 是**单文件压缩流**，不是归档容器；多文件必须走 zip 或 tar 系列。
rar 没有开源写入器，只支持读取；需要写出时先 `arc-convert` 成 zip / tar.gz。

## 默认无需逐项确认（冲突策略）

| 场景 | 默认行为 | 可改 |
|---|---|---|
| 输出路径已存在 | 自动改名 ` (2)`，不询问 | `--on-conflict overwrite\|skip` |
| 批量中某份失败 | 记入汇总，继续下一份 | — |
| 可选依赖缺失 | 自动走标准库路径 | 安装后自动升级 |
| 分卷命名 / 清单 / 临时目录 | 自动决策 | `--output` / `--size` |
| 包内条目重名（add / merge） | 自动加 ` (2)` | — |
| 临时目录清理 | 只清理本技能自己创建的 | — |

**不放行的安全底线**（拒绝即退出，不询问）：
- 归档内绝对路径、`C:` 盘符、`..` 越界 → 退出码 7；
- tar 符号链接 / 硬链接 / 设备文件 → 默认跳过并告警，`--allow-links` 只静默跳过、仍不创建；
- 输出等于输入、输出覆盖原包 → 退出码 3；
- 不主动删除任何用户文件；`arc-remove` 只产出剔除后的新包。

## 加密说明（重要）

- `arc-encrypt` 优先 `pyzipper` 的 WinZip AES-256；未安装时用本技能自带的标准库实现写传统 PKZIP ZipCrypto 加密条目（`flag_bits & 0x1`），标准 `zipfile` 可用 `pwd=` 解开。
- **ZipCrypto 是已知的弱加密**，只防误看与随手打不开，不适用于敏感数据、合规传输或长期归档。输出与交付中必须如实标注算法。
- 加密写入时压缩方法为 deflate，包内不含目录条目；跨格式转换会丢失部分元信息（Unix 权限位、精确时间戳、链接、注释）。
- 密码只在进程内存中使用，不写入日志、不落盘、不回显；密码遗失无法找回。

## 退出码

| 码 | 含义 | 处理 |
|---|---|---|
| 0 | 成功 | 继续 |
| 2 | 用法错误 / 缺可选依赖 | 修参数，或按提示安装可选库 |
| 3 | 输入输出错误（不存在、输出=输入、格式不支持） | 检查路径与扩展名 |
| 4 | 包损坏 / 完整性校验失败 | 重新获取原包，勿继续解包 |
| 5 | 动作执行失败 | 看 stderr |
| 6 | 缺密码 / 密码错误 | 补 `--password` |
| 7 | 安全拒绝（路径穿越等） | 不要强行绕过，换可信来源 |

## 常见排错

- `BadZipFile: File is not a zip file` → 扩展名与实际内容不符，用 `--format` 显式指定。
- `输出不得等于输入` → 本技能从不原地改写压缩包，换一个 `--output`。
- 压缩率为负 → 大量小文件被元数据撑大，属正常；改用 `tar` + 外部压缩或合并文件。
- 中文文件名乱码 → 本技能写出统一用 UTF-8 标志位；外来老包若是 GBK 编码，先在系统解压工具里转存。
- `arc-split` 单卷超上限 → 单个文件本身大于 `--size`，会单独成卷并在 stderr 提示。
