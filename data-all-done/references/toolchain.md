# 运行环境与排错

## 依赖

**零必需依赖**：全部动作只用 Python 3.9+ 标准库（`csv` / `json` / `tomllib`（3.11+，
低版本自动降级） / `xml.etree.ElementTree` / `re` / `argparse`）。
`PyYAML` 是可选增强：装了就用完整 YAML 解析，没装则用内置的极简 YAML 子集。

`python scripts/actions.py check` 会打印当前解释器路径——最常见的「跑不起来」
其实是**用错了解释器**（宿主内置 Python 与系统 Python 混用），而不是缺包。

## 退出码

| 码 | 含义 | 典型原因 |
| --- | --- | --- |
| 0 | 成功 | — |
| 2 | 参数错误 | 格式不支持、`--where` 表达式非法、缺 `--by` |
| 3 | 输入输出冲突 | 输入不存在、输出等于输入、输出是目录 |
| 5 | 动作失败 | 解析失败、编码错误、单份文件处理异常 |

## 格式矩阵

| 格式 | 读 | 写 | 说明 |
| --- | --- | --- | --- |
| csv / tsv | 是 | 是 | 首行为表头，UTF-8 |
| json | 是 | 是 | 接受数组、`{"data": [...]}`、单对象 |
| ndjson | 是 | 是 | 每行一条记录 |
| xml | 是 | 是 | `<rows><row><字段>值</字段></row></rows>` |
| yaml | 子集/完整 | 子集/完整 | 装 PyYAML 时完整支持 |
| toml | 是 | 是 | 写为 `[[rows]]` 数组表 |
| md | 否 | 是 | Markdown 管道表格 |

## 排错清单

- **转 CSV 后全是 `[object Object]` 或空列**：源是嵌套 JSON，先跑 `data_flatten`。
- **中文乱码**：用 `text-all-done` 的 `txt-convert --check` 看编码，必要时先转成 UTF-8。
- **YAML 读出来结构不对**：内置子集不支持锚点/块标量，装 PyYAML 或改用 JSON。
- **筛选命中 0 条**：`=` 两侧要有空格；数值比较请确认字段里没有千分位逗号。
