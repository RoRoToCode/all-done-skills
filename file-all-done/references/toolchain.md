# 运行环境与排错

## 依赖

**零第三方依赖**：全部动作只用 Python 3.9+ 标准库（`argparse` / `json` / `csv` /
`hashlib` / `pathlib` / `fnmatch` / `shutil` / `datetime`）。不需要 pip，不需要联网，
不需要外部二进制。

`python scripts/actions.py check` 会打印当前解释器路径——最常见的「跑不起来」
其实是**用错了解释器**（宿主内置 Python 与系统 Python 混用），而不是缺包。

## 退出码

| 码 | 含义 | 典型原因 |
| --- | --- | --- |
| 0 | 成功 | — |
| 2 | 参数错误 | 缺必填参数、算法名不支持、模板变量非法 |
| 3 | 输入输出冲突 | 输入不存在、输出等于输入、输出落在输入内部 |
| 5 | 动作失败 | 读取失败、单份文件处理异常 |
| 7 | 安全拒绝 | 路径越界、符号链接逃逸、试图写入受保护位置 |

## 输出约定

- 结果统一为一行 JSON（`ensure_ascii=False`），机器读取请用 `-o` 写文件而非抓 stdout。
- 默认不改动任何原文件；`--apply` 是重命名与归类的唯一落盘开关。
- 产物重名自动加 `-2`/`-3`，不覆盖历史结果。
- 批量动作单份失败不中断整批，末尾汇总 `failed` 列表。

## 排错清单

- **预览里没有目标文件**：检查 `--pattern` 与 `--include-hidden`，默认不收隐藏文件、不跟随符号链接。
- **清单被截断**：`--limit` 默认为 0（不限），但树与清单有内置安全上限，报告里的 `truncated` 会说明。
- **哈希很慢**：先用 `--min-size` 与 `--pattern` 缩小范围，`--algo blake2b` 在大文件上通常更快。
- **重命名后找不到文件**：看同目录的 `rename-map.json`，里面是原名→新名的完整映射。
